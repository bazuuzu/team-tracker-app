# Трекер задач — мини-приложение Telegram

Статическая страница-дашборд, которая открывается кнопкой в боте.

- В репозитории только код страницы: здесь нет задач, имён, Telegram ID, токенов или ключей.
- Данные выдаёт сценарий Make и только после проверки подписи Telegram (`initData`) и членства пользователя в команде.
- Открытая в обычном браузере страница ничего не покажет.
